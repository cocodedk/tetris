# Security policy

Tetris is a static site: HTML, CSS and JavaScript served by GitHub Pages, with no server, no
accounts and no data sent anywhere. It stores only your best score and settings in your
browser's `localStorage`.

## Reporting a vulnerability

Email **babak@cocode.dk** with what you found, how to reproduce it and what an attacker could
do with it. Please do not open a public issue for a security problem.

You will get a reply within a week. Once a fix is published you are welcome to be credited.

## Supported versions

Only the live site at https://tetris.cocode.dk/ and the `main` branch are supported.
